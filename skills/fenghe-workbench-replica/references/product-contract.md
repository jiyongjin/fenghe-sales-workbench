# 产品契约：以当前 V4 本地版为准

## 首屏和工作节奏

核心：“知道下一步、接住灵感、看见积累”。不是 CRM 菜单合集，也不是单纯督办系统。晨间安排重点、白天记录与拜访准备、晚间复盘，构成轻量使用节奏。

首屏顺序：固定导航；CSV 状态/刷新/阅读/明暗；日期/身份、标题和添加；搜索；三空间连续色带；今日进展/灵感与同行快捷入口；左侧矩阵、右侧目标/同行/纪念日；灵感收集区；页脚。

三个空间为主业工作、个人生活、创作成长。最后一个可改名/关闭，关闭只影响导航与当前人物显示范围，不删除数据。

## 页面与动作

| 页面 | 核心内容与真实动作 |
| --- | --- |
| 总览 | 跨空间待办、重要/紧急矩阵、完成反馈、目标、日子提醒、灵感入口、同行 |
| 主业 | 待办、客户资产、销售项目、拜访与营销、复盘 |
| 生活 | 待办、财务、健康、学习、家庭、复盘 |
| 创作 | 待办、内容选题到发布/复盘看板、经营复盘 |
| 灵感 | 速记保存/分类、先阅读后编辑、转待办/内容草稿、规则展开 |
| 目标 | 年/季/月、单位、自动/手动来源、达成率、修改、导出 |
| 设置 | 人物资料、创作开关、主题/日夜/字号/密度/背景、CSV目录与AI未连接说明 |

客户S/A/B/C级，联系人、纪念日、偏好、下一行动。列表中偏好默认隐藏；数据本身未加密。项目用 kind 区分线索、商机、交付；阶段枚举必须读取字段字典，不能把三种项目割裂成互不关联的数据孤岛。

任务可分类、完成、撤销、编辑、关联客户/项目/手记。客户、项目、活动、家庭记录可转待办。关联必须同人物，项目的客户与任务/活动所选客户需要一致。被引用的记录删除前必须解除关系。

## 四象限与进展

important = importance为重要；urgent = urgency为紧急，或者due非空且due不晚于今天。已完成从矩阵移除。

二维布局左上“立即行动”，右上“主动规划”，左下“快速处理”，右下“暂缓整理”。同象限按due升序，空日期排最后。手机显示四个切换按钮与当前象限，也可显式切清单。

今日完成数按completed_at=今天计算。进展分母为今日完成数+未完成且到期数；不同于当前全部待办数，不冒充绩效。未来事项今天提前完成也计入今天进展。

## 复盘

默认阅读，最近保存优先；没有保存时实时预览。选择实时预览可重新汇总当前CSV。日报=当天；周报=包含今天的最近7天；月报=本月1日至今天。完成任务按completed_at落入区间，待办是当前未完成事项，目标数字是当前目标周期累计而非本期新增。灵感以date落入区间。

编辑要点击明确按钮。保存写reviews.csv并回到阅读，刷新后可看到最新保存版本；可选历史记录并下载Markdown。不是直接展示原始Markdown代码或把textarea作为默认阅读页面。

## 灵感与同行

手记保存到notes.csv，类型包含灵感、心得、速记、教练建议；快捷输入只选前三类。手记详情先阅读，转换先打开可编辑草稿；只有用户保存才创建任务/内容并写note_id。无需立即把所有想法变成任务。

同行是确定性的离线规则，不调用WorkBuddy当前模型，不外发数据。四入口为今日安排、拜访准备、灵感展开、晚间复盘。疲惫时今日安排只推荐1项，其他状态最多3项；不是情绪诊断。自由问题不支持时说明限制。建议收藏到notes；采纳可开任务或选题草稿。AI接入入口只提供未连接说明和接入清单，尚无真实模型配置/请求。

## 非目标与不能冒充的能力

未接日历、银行、穿戴设备、自媒体API或自动模型；复盘不是LLM创作；年龄由生日计算。CSV为个人单机优先，不提供多人数据库级并发保证。人物过滤不是登录鉴权。手机布局适配不代表能访问另一台电脑的127.0.0.1或磁盘。桌面目录授权能力不可用时必须显示预览/未连接，不能假装保存。
