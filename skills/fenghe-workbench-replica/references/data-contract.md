# 数据契约

完整字段、类型、枚举、默认值与表头在 `data-dictionary.json`，由实际 `SCHEMAS / columnsFor / defaultsFor` 导出。不要只凭本文件的摘要创建表。数据生成规则在 `assets/blueprint/lib/workbench-model.mjs`。

## 主键、文件与关系

13文件：profiles/tasks/goals/customers/projects/activities/finance/health/learning/family/content/notes/reviews.csv。

profiles为id主键；其他表含id,user_id；所有表含updated_at。跨人物关系不合法，客户与项目不匹配不合法。模型关系字段见字典中的type=relation和table。当前引用保护覆盖所有关系字段，包括tasks.note_id、content.note_id；不要只检查客户关系。

CSV使用UTF-8+BOM，字段都是字符串；数值校验/计算时转换。引号、逗号、中文、多行必须可往返。写前备份，服务端串行队列、临时文件+rename；revision基于原始文件SHA256。浏览器目录适配revision采用原文比较，它不是同等数据库并发保障。未知自定义列写回时保留。

## 周期与单位

按Asia/Shanghai今天计算，日期YYYY-MM-DD。年度index=1；季度1–4；月份1–12；目标值>0。周期上界是自然周期最后一天，汇总包含起止日。四象限紧急判断使用due<=今天。

| 来源 | 汇总规则 | 允许单位 |
| --- | --- | --- |
| 手动填写 | actual | 自定义 |
| 完成待办数 | 当前人物+同area+已完成+completed_at在周期 | 个/项/次 |
| 发布内容数 | 当前人物+已发布或已复盘+publish_date在周期 | 个/篇/条 |
| 收入合计 | 当前人物finance的收入+date在周期 | 元/万元 |
| 运动分钟数 | 当前人物health.exercise+date在周期 | 分钟/小时 |
| 学习分钟数 | 当前人物learning.completed+date在周期 | 分钟/小时 |

万元=元/10000；小时=分钟/60。达成率显示真实数值，视觉条最多100%。年/季/月不是自动拆分/汇总关系。收入不是利润，记录账户余额不是银行实时余额；学习时长按学习记录日期归属累计值，不是逐分钟打卡。

## DEMO

`seed-demo.mjs`从源码函数生成新数据。永进是演示ToB销售，致远是演示顾问，后者创作关闭。9项默认主人物待办分布：工作4、生活3、创作2；另一个人物1项。默认四象限分布3/4/1/1。两个客户与3项目覆盖线索/商机/交付。5条健康记录运动合计175分钟，1篇已发布内容，2则手记；reviews初始为空，首次保存才出现记录。

固定手动目标读数：1268/1860万元=68.17%；7/12次=58.33%；第二人物咨询收入22000/50000元=44%。发布/运动采用自动来源：只有相对日期落在目标周期内才统计，因此月初不一定是1/8篇或175/600分钟。例：2026-11-01生成时，3天前发布的内容不属于11月，月度内容达成0；5条运动只有当天25分钟属于11月，达成25/600。175是五条健康记录的总分钟，不是恒定的当月值。具体ID以生成CSV与模型为准，不使用早期原型ACC/OPP编码冒充当前主键。

冻结快照在 `assets/demo-fixture`，日期见DEMO-MANIFEST.json；动态生成更适合后续视频演示。严禁从用户正在使用的data读取真实记录混入DEMO。

## 升级与隐私

缺少的表可补齐，已有CSV不覆盖；旧profiles缺少text_size/density时使用舒适/专注。主题别名读取映射：简约→云境、热情→曜金、冷静→潮汐；不要仅为读取就重写原文件。

人物切换只提供产品级分组和关联检查，不构成账号安全隔离；同机使用者能读取CSV。偏好遮挡只影响UI，不加密磁盘或API。财务、健康和偏好均为敏感资料，默认不外传。数据目录不随Skill、源码包或云端源码发布。
