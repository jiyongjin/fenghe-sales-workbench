# 设计契约

精确实现以蓝本 `workbench.css` 和 `experience.css` 为准，`design-tokens.json` 从它们提取基础变量。禁止另套通用后台模板或把截图里的小字当作目标字号。

## 构图

连续画布与分隔线组织内容；经营色带横向相连，工作蓝、生活橙、创作青；四象限的边界有业务含义，不是任意卡片拼贴。矩阵有大号数量、优先级说明、可完成事项与日期；右侧目标用连续进度条。

桌面导航约80px，主体最大1340px（1550px以上约1420px），侧内边距34px。标题最大44px，桌面双栏，右栏约340px；不同断点以CSS为准。860px以下移动导航/单栏，540px以下手机矩阵，360px以下继续调整。

## 主题与阅读

| 名称 | 主色/气质 |
| --- | --- |
| 云境 CLOUD | #245cd4 钴蓝/银白，默认 |
| 曜金 AUREUM | #996018 琥珀暖金/深墨 |
| 潮汐 TIDE | #087e81 青碧/海蓝 |

夜间使用独立ink、muted、paper、accent、on-accent等变量。不要反色滤镜；不要把用户的旧“简约/热情/冷静”重新展示成新主题名。

标准正文15px、舒适16px、大字18px；舒适辅助12–13px，大字辅助14–15px。手机不缩小正文。标题、说明、数据、编辑控件都应有层级，不应所有字一样大。

专注清单约72px，大字约82px；舒展清单约92px。矩阵任务行独立约80px，不能宣称整个应用所有组件都受密度控制。修改应保留源码实际行为。

背景支持流光、纯净、上传图片覆盖与0–90遮罩；0必须真能保存，不能用逻辑或误回退到默认35。遮罩与画布共同保证可读。用户背景不随演示包携带。

## 交互

动效用于进入、进展、手记保存和反馈，约0.16–0.45秒；减少动态效果时禁用。不得用假流式输出或思考动效暗示连接了模型。点击目标打开编辑，手记先阅览，复盘先阅读，矩阵切换真实影响展示。

键盘焦点可见；图标按钮有中文可访问名称；弹层支持关闭与焦点限制；表单明确标签/错误。危险动作二次确认且保留CSV备份。手机输入字号不低于16px，320px宽下教练输入区域应在可见范围，长文内部滚动。
