# 精准复刻验收清单

## 可自动验收

执行 `node scripts/verify-replica.mjs --target <副本>`。应校验来源哈希（定制另用--allow-modified），在自己的临时数据和自动测试端口执行：

- 13张表、2人物、虚构记录、基础关系合法。
- 无token写入403；不将token输出。
- 灵感含中文/逗号/引号/换行可保存、读取和导出。
- 灵感转任务保留note_id，跨人物关联被拒绝。
- 同一旧revision二次写入被409拒绝，不覆盖记录。
- 被任务引用的手记不能删除。
- 复盘正文写入reviews，停止测试服务后重启仍存在。
- 静态首页与引用的脚本/样式可读取。
- 自己的子进程完成后关闭；原4318程序不受影响。

另外在安装依赖后运行蓝本 `npm run typecheck`、`npm test` 和 `npm run build:local`。源码内原有10项测试覆盖CSV往返、重启、人物/关系、导入原子性、配置兼容、复盘周期、教练模板和HTTP操作。

## 浏览器与人工验收

没有浏览器工具时标记“未重验”，不能照抄历史截图或本清单作为通过证明。

1. 1440px桌面：连续三色带、四象限二维关系、右侧目标，不是全卡片模板。
2. 375px手机：四象限概览点击真正切换内容，清单开关可显示全部。
3. 320px窄屏：无页面横溢，同行输入框可见，长建议在消息区域滚动。
4. 默认正文16px，大字18px；手机不缩小正文。
5. 三主题×日夜、字号、密度、图片/遮罩0都可操作；刷新后保留设置。
6. 完成任务：从待办消失、进展环变化；已完成视图可撤销。
7. 切第二人物：只显示其业务；创作关闭不出现在首页/搜索/目标。
8. 新建万元/元/个目标；自动来源单位不匹配有错误；超过100%真实显示。
9. 灵感保存→阅读→编辑→转待办/选题草稿→用户保存→来源关联仍在。
10. 复盘默认没有编辑框；显式编辑保存后返回阅读，刷新仍可选择版本。
11. 同行说明“规则辅助，未连接大模型”；四入口可用，建议可收藏；不声称联网AI。
12. 键盘焦点/ESC/减少动态效果可用；预览未连接时保存不能伪成功。

## 交付判断

“精准复制”至少是蓝本核心文件未改（或差异经授权）、自动程序验收通过。视觉重验、WorkBuddy客户端导入、云端发布分别单独报告。不要把其中一项通过推论成其他全部通过。
