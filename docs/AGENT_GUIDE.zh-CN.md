# 通用智能体协作指南

本项目不以WorkBuddy或任何单一产品为前提。具备获授权的本地文件、终端工具的智能体可使用相同规范；有浏览器工具时再增加视觉验收。只有聊天、没有文件/终端工具的模型可以帮助规划，但不能宣称已经创建或运行项目。

## 三个不同层次

| 层次 | 含义 | 当前状态 |
| --- | --- | --- |
| 独立应用 | 本机Node服务与网页 | 不需要智能体即可运行 |
| 智能体协作 | 读规范/源码，复刻、定制、构建、测试 | 提供通用文档、提示词和脚本；取决于实际工具与授权 |
| 应用内模型 | 工作台调用外部大模型 | 未接入；同行为离线规则，不共享宿主智能体模型 |

不要把这三者混为“已集成所有AI平台”。

## 开始协作

1. 要求智能体读取README.md、AGENTS.md和本指南。
2. 明确是运行、复刻、定制还是资料辅助，并指定允许写入的目录。
3. 优先用虚构DEMO；真实资料只能在具体授权范围处理，不自动将data加入模型上下文。
4. 要求报告实际执行命令、修改文件、结果与未验证内容。

自动发现AGENTS.md/SKILL.md的机制因工具而异。不支持自动加载时可显式读取。WorkBuddy、Codex、Claude Code等只是可选示例，不是必须依赖、官方连接器或全部实测兼容的声明。本仓库不要求固定隐藏安装目录，不自动安装全局技能。

## 运行应用

```shell
npm ci
npm run build:local
npm start
```

前台服务不是永久后台。Windows构建后可用启动CMD/PowerShell独立启动；电脑重启后仍需重新启动。副本端口冲突时设置WORKBENCH_PORT，不终止原程序。

## 精准复刻

先读取skills/fenghe-workbench-replica/SKILL.md。支持技能导入的工具可以按其机制启用，不支持的工具直接阅读执行，不伪装安装成功。

```shell
node skills/fenghe-workbench-replica/scripts/replicate.mjs --target ../fenghe-sales-workbench-copy
node skills/fenghe-workbench-replica/scripts/verify-replica.mjs --target ../fenghe-sales-workbench-copy
```

目标必须新建或为空，并在用户授权范围内。默认不复制真实data；首次运行创建当前日期的虚构DEMO。只有提示词没有代码/图片时，应称为按规范重建，不承诺逐像素一致。复制结果应保留LICENSE及第三方声明；哈希清单只校验蓝本一致性，不是数字签名或安全审计。

## 定制与维护

使用[通用任务模板](AGENT_PROMPTS.md)，仅修改用户指定范围。不要擅自更换CSV、引入多租户架构、连接模型或发布。界面/数据/运行规则分别阅读Skill中的对应契约。

```shell
npm run typecheck
npm test
npm run build:local
```

定制后可使用verify-replica的--allow-modified，但要列出差异并核对授权。程序测试、运行验收、浏览器检查和某客户端导入是不同结果，分别报告。

## 辅助业务资料

可从用户提供的脱敏纪要整理事实、提问清单、下一行动和复盘草稿。写出文件不等于已导入工作台；用户确认后才按授权方式保存，并保留人物/客户/项目/来源关系。默认不外发真实财务、健康、客户偏好，不自动联系客户或发送消息。

## 交付要求

报告完成内容、修改文件、实际执行及结果、数据/权限范围、启动方式/实际地址、未完成与未验证内容。不能用历史参考图当新截图，不能因宿主智能体能聊天就声称工作台已接大模型。
