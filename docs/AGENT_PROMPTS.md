# 通用任务提示词 / Reusable agent task briefs

适用于具备相应文件/终端权限的智能体，不限WorkBuddy。请指定授权输出路径；提示词本身不授予额外权限。

## 运行 / Run

```text
先读README.md、AGENTS.md。检查Node环境，在当前仓库安装依赖、构建并运行。
使用虚构DEMO，不读取其他data。端口冲突为副本选新端口，不停止原进程。
报告实际命令、地址、结果与限制。
```

```text
Read README.en.md and AGENTS.md. Check Node, install dependencies, build,
and run using fictional demos. Do not read other data directories or stop
existing services. Report actual commands, address, results, and limits.
```

## 复刻 / Reproduce

```text
读README.md、AGENTS.md、docs/AGENT_GUIDE.zh-CN.md与复刻SKILL.md，
在我授权的新空目录复刻。复用蓝本和脚本，保留CSV、主题、四象限、灵感、
复盘阅读与离线教练。不覆盖原data，不发布、不接模型、不扩大网络可见性。
执行可用验证；浏览器或客户端没验就明确标注，不用历史图代替证据。
```

```text
Read README.en.md, AGENTS.md, the agent guide, and replication SKILL.md.
Reproduce in the new empty directory I authorize. Reuse the blueprint and
scripts. Preserve CSV, themes, quadrants, notes, reading-first reviews, and
offline Companion. Do not overwrite data, publish, connect models, or
expand network access. Run checks and report untested browser/client work.
```

## 定制 / Customize

```text
按工程规范在副本中仅修改我指定范围。说明涉及文件与关系；保留未知CSV列、
备份、revision、人物范围和note_id。完成后运行类型检查、测试、构建。
不要顺带改存储架构、接模型或发布。
```

```text
Customize only my requested scope in a copy. Identify affected files and
relations. Preserve unknown CSV columns, backups, revisions, profile scope,
and note_id. Run type checks, tests, and build. Avoid unrelated storage,
model, or publishing changes.
```

## 脱敏资料辅助 / Sanitized-note assistance

```text
根据我提供的脱敏纪要整理事实、待确认问题、下一行动建议与复盘草稿。
不猜测客户承诺或金额，不读取真实data，不自动联系客户。先给可审阅草稿，
确认采纳后才按授权方式保存。
```

```text
Use my sanitized notes to separate facts, open questions, proposed actions,
and a review draft. Do not invent commitments/amounts, read operational
data, or contact customers. Draft first; save only after acceptance.
```
